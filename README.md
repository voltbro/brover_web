# brover_web — agro/final2026

Ветка `agro/final2026` содержит веб-интерфейс BRover-E5 для работы с комплектом
расширения «Транспортировка растений». Помимо базового управления ровером,
интерфейс управляет одной камерой и подъёмом схвата через плату VBCores
ServoBoard, подключённую к `CAN1`.

## Отличия от main

- интерфейс рассчитан на одну видеокамеру;
- добавлено управление сервоприводами поворота и наклона камеры;
- добавлено управление подъёмом и опусканием схвата;
- добавлен ROS 2-узел `transport_control`, преобразующий команды из ROS 2 в
  сообщения CAN FD;
- на телефоне доступны отдельные режимы «Оборудование» и «Движение».

## Возможности интерфейса

- просмотр видео с камеры ровера;
- управление движением с клавиатуры или экранного джойстика;
- ограничение максимальной скорости;
- отображение одометрии и напряжения аккумулятора;
- сброс одометрии;
- управление поворотом и наклоном камеры;
- управление подъёмом схвата при удержании кнопки;
- отображение состояния ROS и Wi-Fi;
- светлая и тёмная темы.

## Схема взаимодействия

```text
Браузер
 ├─ HTTP :8080 ─────→ Flask-сервер brover_web
 ├─ HTTP :9999 ─────→ web_video_server → видео с камеры
 └─ WebSocket :9090 → rosbridge_server → ROS 2
                                           │
                                           ├─ /cmd_vel → управление ровером
                                           └─ /camera/*, /gripper/lift
                                                        ↓
                                               transport_control
                                                        ↓
                                             CAN FD, CAN1, ID 0x100
                                                        ↓
                                             VBCores ServoBoard
                                              ├─ сервоприводы камеры
                                              └─ сервопривод схвата
```

Веб-страница публикует команды в ROS 2 через `roslib.js`. Узел
`transport_control` принимает команды оборудования, формирует четырёхбайтовое
сообщение CAN FD и отправляет его в интерфейс `can1`.

## Управление с компьютера

### Движение ровера

| Клавиша | Действие |
| --- | --- |
| `W` | движение вперёд |
| `S` | движение назад |
| `A` | поворот влево |
| `D` | поворот вправо |

Ползунок «Максимальная скорость» задаёт ограничение от 10 до 100 процентов.

### Подъём схвата

Кнопки «Поднять» и «Опустить» работают только во время удержания. После
отпускания кнопки, потери указателя, переключения режима или потери фокуса
страницы публикуется команда остановки.

## Управление с телефона

На мобильном экране доступны два режима:

- **Оборудование** — управление камерой и подъёмом схвата;
- **Движение** — экранный джойстик управления ровером.

Переключатель режимов расположен под видеопотоком. В нижней части экрана
показывается напряжение аккумулятора.

## Управление камерой

В интерфейсе используются два ползунка:

| Ползунок | Диапазон интерфейса | Значение для сервопривода |
| --- | --- | --- |
| Поворот | от `-90°` до `90°` | от `160°` до `20°` |
| Наклон | от `-45°` до `45°` | от `0°` до `150°` |

При открытии страницы публикуются исходные значения: поворот `90°`, наклон
`60°`. Команды передаются через топики `/camera/pan` и `/camera/tilt`.

## Управление схватом

Команды передаются через топик `/gripper/lift`:

| Значение | Действие |
| --- | --- |
| `0` | остановка |
| `1` | движение вверх |
| `2` | движение вниз |

Сервопривод работает в диапазоне от `10°` до `150°` с шагом `2°` каждые
50 миллисекунд. Угол `10°` соответствует максимально поднятому положению.

При включении ServoBoard сервопривод автоматически устанавливается в положение
`10°`. Во время сборки шестерёнка устанавливается на вал после инициализации
сервопривода, когда рейка находится в максимально поднятом положении.

Датчик положения и обратная связь от сервопривода не используются. Интерфейс
показывает состояние отправленной команды, а не измеренное положение схвата.

## Подключение оборудования

Raspberry Pi ровера соединён с VBCores ServoBoard через `CAN1`. Исполнительные
устройства подключены к ServoBoard следующим образом:

| Устройство | Назначение | Контакт |
| --- | --- | --- |
| сервопривод камеры | поворот | `PA0` |
| сервопривод камеры | наклон | `PA1` |
| сервопривод схвата | подъём и опускание | `PB0` |

Документация платы:
[docs.vbcores.ru/docs/Hardware/servo-board](https://docs.vbcores.ru/docs/Hardware/servo-board).

## Arduino-скетч

Скетч для ServoBoard находится в файле
[`Arduino/agro_final2026/agro_final2026.ino`](Arduino/agro_final2026/agro_final2026.ino).

Он выполняет следующие задачи:

- инициализирует CAN FD;
- принимает сообщения из FIFO0;
- проверяет CAN ID, тип кадра и длину сообщения;
- задаёт углы двух сервоприводов камеры;
- управляет подъёмом схвата без блокирующей задержки;
- останавливает движение на программных пределах;
- устанавливает схват в максимально поднятое положение при включении.

## Формат CAN-команд

Узел `transport_control` отправляет расширенные сообщения CAN FD с
идентификатором `0x100`.

Полезная нагрузка состоит из четырёх байтов:

| Байт | Содержимое |
| --- | --- |
| `0` | идентификатор устройства |
| `1` | идентификатор команды |
| `2` | значение команды |
| `3` | `0x00`, зарезервирован |

Идентификаторы устройств:

| Устройство | ID |
| --- | --- |
| камера | `0x01` |
| подъём схвата | `0x02` |

Идентификаторы команд:

| Команда | ID |
| --- | --- |
| наклон камеры | `0x01` |
| поворот камеры | `0x02` |
| состояние подъёма схвата | `0x03` |

Для команды подъёма используются значения `0`, `1` и `2`: остановка, движение
вверх и движение вниз соответственно.

## ROS 2-топики

| Направление относительно браузера | Имя | Тип | Назначение |
| --- | --- | --- | --- |
| публикация | `/cmd_vel` | `geometry_msgs/msg/Twist` | управление движением |
| публикация | `/camera/pan` | `std_msgs/msg/Int16` | поворот камеры |
| публикация | `/camera/tilt` | `std_msgs/msg/Int16` | наклон камеры |
| публикация | `/gripper/lift` | `std_msgs/msg/Int16` | подъём, опускание и остановка схвата |
| подписка | `/odom_pose2d` | `geometry_msgs/msg/Pose2D` | координаты и угол ровера |
| подписка | `/bat` | `sensor_msgs/msg/BatteryState` | напряжение аккумулятора |
| сервис | `/odom/reset` | `std_srvs/srv/Empty` | сброс одометрии |

Узел `transport_control` подписывается на три топика оборудования:
`/camera/pan`, `/camera/tilt` и `/gripper/lift`.

## Сборка и запуск

Пакет `brover_web` уже установлен в broverOS и запускается по умолчанию при
загрузке ровера. Launch-файл ветки запускает `web_server`, `rosbridge_server`,
`web_video_server` и `transport_control`.
